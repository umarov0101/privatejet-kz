## Private Jet Astana — премиум лендинг (RU / KZ / EN) с кинематографичным WOW-эффектом

### Структура роутов

Локаль — необязательный параметр в URL: `/{-$locale}/...`

```
/              → русская версия (по умолчанию)
/kz, /kz/...   → казахская версия
/en, /en/...   → английская версия

Страницы:
  /            Главная — кинематографичный hero, преимущества, тарифы, CTA
  /fleet       Автопарк — Hyundai Staria LUXE 360°
  /services    Услуги — VIP-трансфер, почасовая, день, межгород, делегации
  /contact     Контакты — телефон, WhatsApp
```

Шапка: лого "Private Jet" · навигация · переключатель RU/KZ/EN · кнопка «Заказать» (WhatsApp). При скролле шапка превращается в стеклянную (backdrop-blur) с золотой подсветкой.

### Мультиязычность

- Опциональный locale-параметр: `src/routes/{-$locale}/index.tsx` и т.д.
- Локали: `ru` (по умолчанию, без префикса), `kz`, `en`.
- Словари: `src/i18n/{ru,kz,en}.ts` — плоские объекты со всем контентом.
- Хук `useLocale()` + функция `t(key)`.
- Переключатель сохраняет текущую страницу при смене языка.
- У каждой страницы свой `head()` с локализованными meta + `hreflang` + `og:locale`.
- HTML `lang` переключается динамически.

## 🎬 WOW-эффекты при скролле (главное обновление)

Цель — чтобы посетитель залип. Все эффекты на чистом CSS + `IntersectionObserver` + `framer-motion` (для пружинных анимаций), 60fps на мобиле.

### 1. Hero — кинематографичный вход
- **Полноэкранное видео-loop фон**: ночная Astana, медленный pan-shot Staria на фоне Байтерека и Дворца Независимости. Затемнение 60%.
- **Stagger-анимация заголовка**: буквы появляются по одной с blur→clear (как в трейлерах Apple).
- **Парящие золотые частицы** (~30 шт., медленно дрейфуют) — задают атмосферу люкса.
- **Скролл-индикатор** внизу: тонкая золотая линия с мерцающей точкой.

### 2. «Фары загораются» при скролле
- Сразу после hero — тёмный кадр Staria спереди.
- Когда секция входит в viewport, **фары плавно загораются** золотым свечением (CSS-маска + box-shadow с увеличивающимся радиусом).
- Параллельно отблеск пробегает по решётке радиатора (animated gradient).

### 3. «Дверь открывается» в блоке "Кто мы"
- Sticky-секция: слева текст «Кто мы», справа Staria сбоку.
- При скролле раздвижная дверь Staria **сдвигается** (transform: translateX по scrollYProgress), открывая интерьер с капитанскими креслами и янтарной подсветкой салона.
- Эффект достигается двумя слоями PNG (кузов + дверь) с z-index и transform.

### 4. Horizontal scroll — «Тур по Астане»
- Секция, где при вертикальном скролле горизонтально проезжает Staria по силуэту Астаны (Байтерек → Хан Шатыр → Дворец Независимости → аэропорт).
- На каждой остановке всплывает мини-карточка: «Аэропорт NQZ — встречаем с табличкой», «EXPO — деловой район», и т.д.

### 5. Тарифы — 3D-tilt карточки
- Чёрные карточки с золотой каймой.
- На hover — 3D-наклон по курсору (vanilla-tilt эффект через CSS perspective + transform).
- Золотое свечение «дышит» по периметру.
- Цифры цены **анимируются счётчиком** при появлении (0 → 25 000).

### 6. «Капитанское кресло» — параллакс-зум
- Полноэкранная фотография интерьера.
- При скролле камера **медленно зумится** в кресло (transform: scale 1 → 1.3) + параллакс слоёв.
- Подпись справа печатается posimvolно (typewriter).

### 7. Marquee «10 лет на рынке»
- Бесконечная горизонтальная лента: «10 ЛЕТ • PRIVATE JET • ASTANA • LUXE • 24/7 • » огромными засечными буквами с золотым контуром.
- Скорость замедляется при наведении мыши.

### 8. Magnetic-кнопки
- Главные CTA «слегка притягиваются» к курсору (классический Awwwards-приём).

### 9. Reveal-маски на изображениях
- Все фото появляются через **золотую wipe-маску** слева направо (как занавес в кино).

### 10. Финальный CTA — «Подача авто»
- Тёмная сцена. При входе в viewport — Staria **медленно выезжает** из правой части экрана с плавным замедлением (cinematic ease-out), включаются фары, появляется кнопка WhatsApp с золотой пульсацией.

### Производительность
- Все тяжёлые анимации — `transform` / `opacity` (GPU).
- `prefers-reduced-motion` — отключает параллакс/видео, оставляет fade-in.
- На мобиле: видео заменяется статичным hero-фото, horizontal-scroll — вертикальной галереей.
